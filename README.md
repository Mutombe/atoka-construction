# Atoka Construction — website demo

Static demo platform for Atoka Construction by Bit Studio: projects portfolio, online estimate wizard and a building-materials shop (cart, compare, checkout mock-up).

Plain HTML/CSS/JS — no build step. Open `index.html` or serve the folder with any static host.

> Photography is iStock preview imagery for demo purposes only and must be licensed or replaced before launch. Contact details, prices and testimonials are placeholders.
